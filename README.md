# AI Resume Evaluator 

A full-stack web application built with Node.js and Express that allows users to upload their resumes (PDF) and uses AI to evaluate them against a specific Job Description.

## Tech Stack
  Backend: Node.js, Express.js
  File Handling: Multer
  PDF Processing: pdf-parse
  AI Integration: Google Gemini API

## Current Features
  Set up an Express server to handle routing.
  Integrated Multer middleware to securely accept and store PDF file uploads from the user.

(Note: This project is currently in development!)
